# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is
enabled. Otherwise, contact the repository owner privately through their GitHub
profile and include reproduction steps, affected versions, and potential impact.

The maintainer will acknowledge a report as soon as practical and coordinate a
fix and disclosure timeline with the reporter.

## Supported versions

This solo project supports only the latest version on the default branch.
